# Snake
classic snake game

Start:

to start you just type, 'make'.
then you can play by typing, './Main'.

How to play:

you move with 'w/a/s/d'.
and quit with 'q'.
you must press ENTER after every input.

Key Feature:

i used `std::vector` to manage and grow the snake's body segments as it eats food.

End:

after you're done you type, 'make clean'.
